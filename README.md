# VR Warehouse
**VR Warehouse** — учебный VR-проект, разрабатываемый в Unity в рамках командной работы.
## О проекте
Игрок оказывается на виртуальном складе, где взаимодействует с товарами, оборудованием и окружающими объектами.
Проект направлен на создание интерактивного VR-окружения с использованием трёхмерных моделей и игровых механик.
## Технологии
- Unity
- C#
- Blender
- VR
## Структура проекта

- `Assets/` — игровые ресурсы, сцены, модели и скрипты
- `Packages/` — зависимости Unity.
- `ProjectSettings/` — настройки проекта
- `Docs/` — проектная документация
## Организация разработки
Разработка ведётся с использованием GitHub Issues и GitHub Projects.
Изменения в основной ветке проекта вносятся через Pull Requests после проверки.
## Статус проекта
В разработке.
